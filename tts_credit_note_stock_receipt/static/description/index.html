Tts Credit Note Stock Receipt

Seamlessly link your Accounting and Inventory workflows.

Streamline Your Returns

The Tts Credit Note Stock Receipt module bridges the gap between customer credit notes and stock operations. Eliminate manual coordination by allowing your finance team to trigger stock returns directly from the credit note, ensuring inventory accuracy and operational efficiency.

Odoo Enterprise Odoo Community Odoo.sh

Note: This module contains custom Python logic and is compatible with Odoo.sh and On-Premise/Cloud hosting. It is not compatible with Odoo Online (SaaS) which does not support custom Python modules.

Key Features

Warehouse Selection

Select the specific return warehouse directly on the Credit Note form.

Automation

Automatically generates a confirmed Stock Receipt upon posting the credit note.

Smart Access

One-click access to the linked Stock Picking via a convenient smart button.
